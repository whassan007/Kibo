# KIBO Privacy OS — Phase 0: Regulatory & Technical Gap Analysis

**Date:** 2026-10-25  
**Platform:** KIBO Privacy OS (`https://kibo.is`)  
**Role:** Principal Architect & Autonomous Orchestrator (A0)

---

## 1. Executive Summary of Gaps

To serve as the operational system of record for enterprise privacy offices across the **United States (Federal + 50 States + DC + territories)**, **Canada (Federal + 10 Provinces + 3 Territories)**, and the **European Union (EU-wide + 27 Member States)**, KIBO must bridge eight foundational gaps between its current repository state and the target production architecture.

---

## 4. Enterprise Infrastructure & Integration Gaps

1. **SQLAlchemy Model Collision Bug (Blocker)**: `core/models/assets.py` and `core/modules/vendor_risk/models.py` both register `class Vendor(Base)` on the same declarative registry, crashing SQLAlchemy mapper initialization.
2. **Database & Persistence**: Hardcoded `sqlite:///kibo_state.db` in `agent_gateway.py` and `ontology_store.py`. Must support `DATABASE_URL` (PostgreSQL 16 in production/Docker and isolated SQLite/PostgreSQL in test suites).
3. **Tenant Isolation Across All Layers**: Legacy SQLite tables in `agent_gateway.py` lack `tenant_id` filtering, and MCP/RAG endpoints do not enforce tenant context isolation (required by Acceptance Test 11).
4. **Corporate AI Integrations**:
   - **Microsoft 365 Copilot**: Needs declarative agent manifest (`manifest.json`, `declarativeAgent.json`, `ai-plugin.json`, OpenAPI 3.1 spec) and OAuth2/Entra ID token propagation.
   - **Claude Enterprise**: Needs secure remote/SSE & stdio MCP server exposing Privacy Office tools with server-side tenant authorization and read-only defaults.
   - **Gemini Enterprise**: Needs Vertex AI / Gemini Enterprise OpenAPI & MCP extension package with scoped IAM/OIDC authorization.
5. **LLM Unavailability Resilience**: When LLMs are disabled or unreachable, `run_agent_node()` must cleanly execute deterministic rule evaluation without throwing unhandled errors or fabricating legal conclusions (Acceptance Test 15).
